🎨 Explicação linha a linha • Classes e Seletores CSS

Este exemplo demonstra como usar classes no HTML e seletores no CSS para criar cartões com aparências diferentes. O conceito central: aplicar mais de uma classe ao mesmo elemento HTML e combiná-las para estilos específicos.

📖 Explicação linha por linha

Cada passo abaixo está ancorado a um número de linha do código. Ao clicar em uma linha na aba 1, você será levado ao passo correspondente.

1. Estrutura HTML

Linha 1 — <!DOCTYPE html>

Informa ao navegador que o documento utiliza HTML5, a versão moderna do HTML. Ajuda o navegador a interpretar corretamente os elementos da página.

Em outras palavras: estamos avisando ao navegador qual padrão HTML deve utilizar. Sem essa declaração, o navegador entra em quirks mode e pode renderizar algumas propriedades de forma diferente.

Linha 2 — <html lang="pt-BR">

<html> é o elemento principal do documento — todos os demais ficam dentro dele. lang="pt-BR" informa que o idioma predominante é o português brasileiro.

Por que importa: ajuda leitores de tela a escolher a voz correta; facilita a identificação do idioma pelos mecanismos de busca; permite que navegadores usem recursos relacionados ao idioma (como hifenização).

Linhas 3 a 5 — Cabeçalho do documento

  • Linha 3 — <head>: abre a seção de configurações que não aparecem diretamente na página.
  • Linha 4 — <meta charset="UTF-8">: define a codificação. UTF-8 permite representar acentos, cedilha e símbolos. Sem isso, "programação" poderia virar "programaÃ§Ã£o".
  • Linha 5 — <title>Classes e Seletores</title>: define o título da aba do navegador — não é o título visível dentro da página.

Linha 6 — <style>

Abre uma área destinada a escrever CSS. CSS é a linguagem que define a aparência dos elementos HTML: cores, bordas, espaçamentos, fontes, posicionamento.

Alternativa comum: em vez de <style>, poderia ser um arquivo externo ligado por <link rel="stylesheet" href="estilo.css">. Aqui, para facilitar a cópia em um único arquivo (por exemplo, no OneCompiler), o CSS está embutido.

2. Configurações gerais do CSS

Linha 7 — * { box-sizing: border-box; margin: 0; padding: 0; }

O seletor universal * representa todos os elementos HTML da página.

CódigoSignificado
*Seleciona todos os elementos.
box-sizing: border-box;Faz a largura e a altura incluírem o conteúdo, o padding e a borda.
margin: 0;Remove as margens externas padrão.
padding: 0;Remove os espaçamentos internos padrão.

Diferença entre Margin e Padding

MARGIN — espaço externo
PADDING — espaço interno
CONTEÚDO
  • Margin: distância entre um elemento e os elementos ao seu redor.
  • Padding: distância entre o conteúdo e a borda do próprio elemento.
Versão mais completa no T8: *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } — o mesmo efeito, mais os pseudoelementos. Aqui mantemos a versão curta porque este é o material introdutório.

Linha 8 — body { font-family: Arial, sans-serif; padding: 20px; }

O seletor body seleciona o corpo da página.

PropriedadeSignificado
font-family: Arial, sans-serif;Define Arial como primeira opção. Se não estiver disponível, usa outra fonte sem serifa.
padding: 20px;Cria espaçamento interno de 20 pixels nas quatro direções — afastando o conteúdo das bordas da janela.
Por que duas fontes? Arial não existe em todos os sistemas (Linux, por exemplo, costuma não ter). A segunda família (sans-serif) é uma "reserva" genérica, garantindo que o texto continue legível e sem serifa.

3. Criando a classe .cartao

Linha 9 — .cartao {

Aqui começa a definição de uma classe chamada cartao.

  • O ponto (.) antes do nome indica que estamos selecionando uma classe.
  • cartao é o nome escolhido — poderia ser qualquer outro (a classe não tem significado para o navegador, só para quem lê o código).
  • As propriedades entre chaves serão aplicadas a todos os elementos que usarem essa classe.

Exemplo de uso no HTML:

<div class="cartao">Meu cartão</div>

Linhas 10 a 14 — Propriedades de .cartao

  • Linha 10 — background: #dbeafe; — cor de fundo azul-claro em hexadecimal.
  • Linha 11 — border: 2px solid #2563eb; — borda com 3 partes: espessura (2px), tipo (linha contínua) e cor (azul).
  • Linha 12 — border-radius: 12px; — arredonda os cantos. Quanto maior, mais arredondados.
  • Linha 13 — padding: 16px; — espaçamento interno. Evita que o texto fique encostado nas bordas.
  • Linha 14 — margin-bottom: 12px; — margem apenas embaixo, criando espaço entre este cartão e o próximo.
Observação sobre a linha 11: a propriedade border é um atalho para três propriedades separadas — border-width, border-style e border-color. Você pode escrevê-las separadas se preferir.

Linha 15 — }

Fecha a definição da classe .cartao. Até aqui, criamos um estilo que poderá ser reutilizado em vários elementos HTML.

4. Criando a classe combinada

Linha 16 — .cartao.destaque {

Esta é a parte mais importante do exemplo.

Temos dois nomes de classe — .cartao e .destaque — sem espaço entre eles. Isso significa que o CSS selecionará somente os elementos que possuem as duas classes ao mesmo tempo.

SeletorO que seleciona
.cartaoElementos com a classe cartao.
.destaqueElementos com a classe destaque.
.cartao.destaqueElementos que possuem cartao e destaque ao mesmo tempo.
.cartao .destaqueElementos com a classe destaque que estão dentro de outro elemento com a classe cartao.
⚠️ Atenção: .cartao.destaque (sem espaço) e .cartao .destaque (com espaço) são seletores diferentes. O primeiro é "as duas classes no mesmo elemento"; o segundo é "um elemento dentro do outro".

Linhas 17 a 19 — Propriedades de .cartao.destaque

  • Linha 17 — background: #ffedd5; — altera a cor de fundo para laranja-claro.
  • Linha 18 — border-color: #ea580c; — altera somente a cor da borda. Espessura e tipo continuam os de .cartao porque não foram redefinidos.
  • Linha 19 — font-weight: 700; — define o peso da fonte. 700 normalmente representa negrito.
Por que só redefinimos o que muda? Este é o princípio da herança de estilo entre classes. Ao combinar classes, os estilos de .cartao continuam aplicados; .cartao.destaque só sobrescreve o que precisa mudar. Isso evita duplicar propriedades e mantém o CSS enxuto.

Linha 20 — }

Fecha a definição do seletor combinado.

5. Encerramento do CSS e do HTML

Linhas 21 a 24 — Fechamento do <head> e abertura do <body>

  • Linha 21 — </style>: fecha a área de CSS.
  • Linha 22 — </head>: fecha a seção de configurações.
  • Linha 23 — <body>: inicia o corpo. Tudo aqui será exibido pelo navegador.
  • Linha 24 — <div class="cartao">Cartão normal</div>: cria o primeiro cartão. Elemento <div> como contêiner; a classe cartao liga o elemento ao estilo definido. Ele recebe todos os estilos de .cartao.

Linha 25 — <div class="cartao destaque">Cartão em destaque</div>

O segundo cartão tem duas classes simultâneas: cartao e destaque. Portanto ele recebe:

  • Todas as propriedades de .cartao.
  • As propriedades adicionais de .cartao.destaque.
Resultado: fundo laranja-claro, borda laranja, cantos arredondados e texto em negrito. O formato geral (cantos, espaçamento, tamanho) é o mesmo do primeiro — só as cores e o peso mudam.

Linhas 26 e 27 — Fechamento

</body> fecha o corpo; </html> encerra o documento.

🎯 O conceito mais importante: combinação de classes

Este é o ponto que faz o exemplo valer a pena. Aprender a combinar classes evita duplicar CSS inteiro quando você só precisa mudar cor ou peso em casos específicos.

Como funciona

No HTML, você pode atribuir várias classes ao mesmo elemento separando-as com um espaço:

duas-classes.html
<div class="cartao destaque">Cartão em destaque</div>

No CSS, você seleciona o elemento que tem as duas classes escrevendo os seletores grudados:

seletor-combinado.css
.cartao.destaque { background: #ffedd5; }

Comparação lado a lado

Só a classe cartao
Cartão normal

Fundo azul-claro. Borda azul. Texto normal.

As duas classes: cartao + destaque
Cartão em destaque

Fundo laranja-claro. Borda laranja. Texto em negrito.

Os quatro seletores que você precisa distinguir

SeletorSelecionaOnde aparece
.cartaoQualquer elemento com a classe cartao.Ambos os cartões do exemplo.
.destaqueQualquer elemento com a classe destaque.Só o segundo cartão (que tem essa classe).
.cartao.destaqueElementos com as duas classes ao mesmo tempo.Só o segundo cartão.
.cartao .destaqueElementos com classe destaque que estão dentro de um .cartao.Neste exemplo: nada.
⚠️ Armadilha comum: iniciantes costumam pensar que .cartao .destaque (com espaço) é o mesmo que .cartao.destaque (sem espaço). Não são. O espaço muda completamente o significado do seletor. Sem espaço: "as duas classes no mesmo elemento". Com espaço: "um elemento dentro do outro".

Por que isso é melhor que duplicar CSS?

Imagine fazer o cartão em destaque escrevendo tudo de novo:

sem-combinar.css — não recomendado
.cartao-destaque { background: #ffedd5; border: 2px solid #ea580c; border-radius: 12px; padding: 16px; margin-bottom: 12px; font-weight: 700; }

Isso duplica quatro propriedades (borda completa, raio, padding, margin). Se um dia você mudar a espessura da borda no .cartao, esse cartão em destaque não acompanha — visualmente inconsistente.

Combinando classes, o cartão em destaque herda automaticamente todas as propriedades de .cartao e só redefine o que precisa. Manutenção centralizada, resultado previsível.

🔬 Laboratório: edite e veja o efeito

Ajuste cada propriedade e observe o resultado no cartão de exemplo. O código CSS é atualizado ao vivo.

Cartão normal — só classe cartao
Cartão em destaque — classes cartao e destaque
.cartao { background: #dbeafe; border: 2px solid #2563eb; border-radius: 12px; padding: 16px; margin-bottom: 12px; } .cartao.destaque { background: #ffedd5; border-color: #ea580c; font-weight: 700; }
💡 Experimente: deixe o border-radius: 0 e veja os cantos ficarem retos. Aumente o padding e veja o texto afastar das bordas. Reduza margin-bottom para 0 e veja os cartões se encostarem. Cada mudança mostra o efeito de uma propriedade.

💡 O que acontece quando o navegador interpreta o CSS?

A ordem é importante — cada etapa depende da anterior.

1
O navegador lê o HTML Identifica os elementos e as classes atribuídas a cada um.
2
O navegador interpreta o CSS Identifica os seletores e suas propriedades.
3
Associa as classes aos estilos Aplica cada regra aos elementos que têm a classe correspondente.
4
Exibe a página formatada Cada cartão aparece com sua aparência final.

Aplicando ao exemplo

ElementoClasses aplicadasRegras de estilo recebidas
Primeiro <div> cartao Só .cartao.
Segundo <div> cartao + destaque .cartao + .cartao.destaque (que sobrescreve cor de fundo, cor da borda e peso).
Sobre a especificidade: os dois seletores têm o mesmo peso em termos de classe (cada .classe conta como 1 ponto de especificidade). Por isso o navegador usa a ordem de declaração no arquivo: .cartao.destaque vem depois de .cartao, então prevalece nas propriedades que redefine.
