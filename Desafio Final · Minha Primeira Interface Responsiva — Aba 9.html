🏗️ Arquitetura da página

A página que serve de referência temática é uma loja de café artesanal. A escolha não é arbitrária: um e-commerce exercita Grid (grade de produtos) e Flexbox (cabeçalho, navegação, chip de preço + botão) nos dois papéis mais comuns.

HTML semântico — a espinha dorsal

<header> — título + subtítulo Flexbox
<nav> — menu horizontal Flexbox
<main> Grid
<section class="grade-produtos"> Grid
<article class="cartao"> Flexbox
└─ .cartao-rodape Flexbox (preço + botão)
└─ .cartao-acoes Flexbox (grupo de botões)
<footer> — informações Flexbox
Onde Grid atua: a estrutura da página (main e a grade de produtos). Onde Flexbox atua: os componentes internos (header, nav, cartão, rodapé, grupo de botões). Essa divisão atende literalmente a rubrica — e é a divisão que a Missão 5 da aba 8 defende.

Contagem de Flexbox

A rubrica pede "Flexbox em pelo menos dois componentes internos". A página de referência usa cinco:

#ComponenteO que justifica usar Flex
1.cabecalhoTítulo e subtítulo empilhados, com o badge "artesanal" ao lado do título — alinhamento vertical entre elementos de tamanhos diferentes.
2.navegacaoMenu horizontal de larguras variáveis, sem largura fixa — distribuição flexível no eixo principal.
3.cartaoConteúdo interno em coluna; rodapé do cartão empurrado com margin-top: auto.
4.cartao-acoesPreço e botão lado a lado, com o botão absorvendo o espaço (flex: 1).
5.rodapeTexto de rodapé + links sociais numa linha, alinhados verticalmente.
✅ Cinco componentes com Flexbox > "pelo menos dois". Não copie o número — use-o como referência de proporção. Se você escolher para o seu tema colocar Flexbox em dois e Grid no resto, cumpre a rubrica; com cinco, é folgado.

Onde a media query atua

A página de referência tem uma media query em 768px que faz três mudanças estruturais simultâneas:

  1. A grade de produtos passa de 3 colunas → 1 coluna.
  2. A navegação passa de linha horizontal → empilhada verticalmente.
  3. O cabeçalho passa de linha (título à esquerda, badge à direita) → coluna (título, depois badge).

É uma mudança real, não cosmética. O critério "mudança visível no layout" (peso 2) exige exatamente isso: as três mudanças são detectáveis a olho nu.

⚠️ Por que 768px e não 600? A grade de 3 colunas começa a apertar quando a coluna cai abaixo de ~200px de largura. Com minmax(), a quebra natural aconteceria em torno de 640px. Escolher 768px é uma media query por conveniência pedagógica (alinhada com a aba 4 e a aba 6) — mas a página funciona mesmo sem ela, porque a grade usa repeat(auto-fit, minmax(200px, 1fr)). A media query existe para a rubrica, e é o que o aluno aprende: declarar o breakpoint quando precisa de mudança estrutural, não de ajuste de coluna.

Onde está a media query

Ela fica no final do arquivo, depois de todo o CSS base. Dentro dela há três mudanças visíveis:

@media (max-width: 768px) { /* 1) Grade de produtos: 3 → 1 coluna */ .grade-produtos { grid-template-columns: 1fr; } /* 2) Navegação: linha → coluna */ .navegacao { flex-direction: column; align-items: flex-start; } /* 3) Cabeçalho: linha → coluna */ .cabecalho { flex-direction: column; align-items: flex-start; } }
⚠️ Por que não usar auto-fit só e pular a media query? Porque auto-fit muda a grade mas não muda a navegação nem o cabeçalho. A rubrica exige "mudança visível no layout", e três mudanças são mais convincentes do que uma. Além disso, ensinar uma media query real é o objetivo da aba 9 — o auto-fit é o automatismo que a aba 7 introduziu, mas o exame final exige o passo manual.

2
O seletor universal *, *::before, *::after { box-sizing: border-box; } é importante porque…
a) Deixa o site mais rápido
b) Evita que padding e border somem à largura e causem rolagem horizontal
c) Desativa o CSS padrão do navegador
d) Só serve para deixar as fontes coloridas

✅ Correto! Mudança real = mudança de layout (colunas, eixos, empilhamento). A opção (b) altera colunas do Grid e direção do Flexbox, o que é visível a olho nu. As demais alteram apenas tamanho de texto, cor ou espaçamento — não contam.

Sem ele, entre 768px e 900px o cabeçalho geraria rolagem horizontal. A media query e o wrap atuam em faixas diferentes, e combinados garantem continuidade.
