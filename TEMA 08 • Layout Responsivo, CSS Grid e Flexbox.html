🖥 Por que os sites precisam se adaptar?

O mesmo site é acessado por telas muito diferentes. Um layout fixo funcionaria para um único tamanho — e ficaria ruim em todos os outros. Um layout responsivo reorganiza elementos conforme o espaço disponível.

📌 Analogia: um layout responsivo é como um móvel modulável. A estrutura (o que existe) é a mesma; a organização (como as peças se encaixam) muda conforme o espaço.

O que é layout

Layout é a forma como os elementos se organizam na tela: o que fica à esquerda, à direita, acima ou abaixo, qual área é maior, quais elementos formam um grupo.

Benefícios de um layout responsivo

BenefícioPor que importa
AcessibilidadeFunciona em celular, tablet, computador e leitores de tela.
Experiência do usuárioSem zoom, sem rolagem horizontal, textos legíveis.
ManutençãoUm único código CSS atende vários dispositivos.
SEOBuscadores priorizam páginas responsivas.

Critérios de otimização de layout

  • Sem rolagem horizontal: conteúdo cabe na largura da tela.
  • Legibilidade: fontes e espaçamentos confortáveis em todas as larguras.
  • Hierarquia preservada: o que é importante continua visível e destacado.
  • Alvos de toque: botões e links grandes o suficiente no celular (recomendado ≥ 44px).
  • Sem conteúdo cortado: tabelas, imagens e formulários se ajustam.

🧩 Atividade de identificação

Abra um site qualquer no computador. Reduza a janela até ficar estreita (ou abra o DevTools e ative a visualização mobile). Anote:

  1. O menu horizontal continua na mesma linha ou virou um botão "☰"?
  2. Os cartões continuam lado a lado ou empilharam?
  3. Aparece rolagem horizontal?
  4. Algum texto fica ilegível ou cortado?
⚠️ Não é sobre adivinhar: teste em pelo menos três larguras — por exemplo 1024px, 720px e 360px. É o mesmo exercício que faremos em todos os laboratórios deste material.

🧱 Preparação: o que já sabemos

Antes de aprender Grid e Flexbox, revise os conceitos que vão aparecer o tempo todo. Esta não é uma aula nova — é uma checagem rápida.

HTML como estrutura

O HTML descreve o que existe na página (cabeçalho, menu, conteúdo, rodapé). O CSS descreve como isso se organiza visualmente. Grid e Flexbox são recursos de CSS — não alteram o HTML.

Classes e seletores

Classes permitem aplicar estilo a grupos de elementos. Veja o exemplo abaixo — repare que .cartao aplica o estilo base e .cartao.destaque sobrescreve algumas propriedades:

classes-e-seletores.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Classes e Seletores</title> <style> * { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, sans-serif; padding: 20px; } .cartao { background: #dbeafe; border: 2px solid #2563eb; border-radius: 12px; padding: 16px; margin-bottom: 12px; } .cartao.destaque { background: #ffedd5; border-color: #ea580c; font-weight: 700; } </style> </head> <body> <div class="cartao">Cartão normal</div> <div class="cartao destaque">Cartão em destaque</div> </body> </html>

Box Model — revisão de 60 segundos

Todo elemento é uma caixa com quatro áreas: conteúdo, padding, border e margin. A regra que mais importa aqui:

Regra de ouro: sempre adicione * { box-sizing: border-box; } no início do CSS. Assim, width e padding trabalham juntos sem estourar o layout — fundamental quando lidamos com Grid e Flexbox.

🔵 CSS Grid: organizar a estrutura

Grid divide o espaço em linhas e colunas como uma planilha. Você declara quantas colunas e quais proporções, e posiciona os itens nessas células.

Grid container e grid items

Você aplica display: grid no container. Os filhos diretos tornam-se grid items automaticamente.

1
2
3
4
5
6
.container { display: grid; grid-template-columns: 1fr 1fr; gap: 8px; }

O que grid-template-columns faz

Define quantas colunas o grid tem e a largura de cada uma. 1fr 1fr = duas colunas que dividem o espaço igualmente.

  • 1fr 2fr → a segunda coluna tem o dobro do tamanho.
  • 200px 1fr → primeira fixa em 200px, segunda ocupa o restante.
  • repeat(3, 1fr) → três colunas iguais (atalho).

grid-template-rows

O mesmo raciocínio para linhas. Em muitos casos a altura das linhas é automática (definida pelo conteúdo) — você só define grid-template-rows quando quer controlar alturas específicas.

  • auto 1fr auto → cabeçalho e rodapé com altura do conteúdo, meio ocupando o resto (layout clássico de página).
  • repeat(2, 100px) → duas linhas de 100px.

A unidade fr

fr = fração. O espaço disponível é dividido em frações. Com grid-template-columns: 1fr 2fr 1fr, a soma é 4fr: a primeira ocupa 1/4, a segunda 2/4, a terceira 1/4.

gap, row-gap, column-gap

Criam espaçamento entre os itens (não em volta do container).

  • gap: 16px → o mesmo espaçamento entre linhas e colunas.
  • gap: 8px 24px → 8px entre linhas, 24px entre colunas.

grid-template-areas

Você "desenha" o layout usando nomes. Cada string é uma linha; cada palavra é uma coluna. Áreas com o mesmo nome ocupam mais de uma célula.

areas.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Grid Template Areas</title> <style> *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, sans-serif; padding: 16px; } .pagina { display: grid; gap: 10px; grid-template-columns: 180px 1fr; grid-template-rows: auto 1fr auto; grid-template-areas: "cabecalho cabecalho" "menu conteudo" "rodape rodape"; min-height: 320px; } .cabecalho { grid-area: cabecalho; background: #1e3a8a; color: #fff; padding: 14px; border-radius: 8px; } .menu { grid-area: menu; background: #93c5fd; padding: 14px; border-radius: 8px; } .conteudo { grid-area: conteudo; background: #e0e7ff; padding: 14px; border-radius: 8px; } .rodape { grid-area: rodape; background: #334155; color: #fff; padding: 14px; border-radius: 8px; } </style> </head> <body> <div class="pagina"> <header class="cabecalho">Cabeçalho</header> <nav class="menu">Menu</nav> <main class="conteudo">Conteúdo principal</main> <footer class="rodape">Rodapé</footer> </div> </body> </html>

Alinhamento: justify-items x align-items x justify-content x align-content

Essas quatro propriedades são as que mais confundem — e a melhor forma de entender é mexer nelas ao vivo. Use os seletores abaixo e observe o que muda no palco:

1
2
3
4
5
6
.container { display: grid; grid-template-columns: repeat(3, 90px); gap: 8px; justify-items: stretch; align-items: stretch; justify-content: normal; align-content: normal; }
O que observar:
  • justify-items / align-items mexem no conteúdo de cada célula (as caixas azuis).
  • justify-content / align-content mexem no conjunto todo do grid quando sobra espaço no container.
  • Como o alvo tem width e height = 100%, o grid ocupa todo o palco — por isso justify-content e align-content não têm efeito visível agora. É exatamente a confusão do dia a dia: eles só funcionam quando o grid é menor que o container.
  • Para ver justify-content e align-content funcionando, imagine um grid com width: 400px dentro de um container de 900px — aí sobra espaço e as opções center, end, space-between passam a ter efeito.
⚠️ Confusão comum: se você aplicou justify-content: center e "nada aconteceu", não é bug — é porque o grid já ocupa 100% da largura. As opções *-content só distribuem espaço livre. Sem espaço livre, não há o que distribuir. As opções *-items funcionam sempre, porque agem dentro de cada célula.

Veja o efeito das quatro propriedades em um exemplo completo. O exemplo abaixo fixa o grid em width: 400px para que sobre espaço e você consiga ver justify-content e align-content agindo:

alinhamento-grid.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <title>Alinhamento no Grid</title> <style> *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, sans-serif; padding: 20px; background: #f8fafc; } h2 { color: #1e3a8a; margin-bottom: 6px; } p.dica { color: #475569; margin-bottom: 16px; font-size: 14px; } .container { /* O container ocupa 100% da largura disponível */ width: 100%; min-height: 320px; background: #e0e7ff; border: 2px dashed #94a3b8; padding: 8px; margin-bottom: 24px; /* O grid tem 300px x 200px — MENOR que o container, então sobra espaço para justify-content / align-content agirem */ display: grid; grid-template-columns: repeat(3, 90px); grid-template-rows: repeat(2, 90px); gap: 6px; /* As 4 propriedades mágicas */ justify-items: center; /* conteúdo da célula no eixo horizontal */ align-items: center; /* conteúdo da célula no eixo vertical */ justify-content: center; /* grid inteiro no eixo horizontal */ align-content: center; /* grid inteiro no eixo vertical */ } .cx { width: 60px; height: 60px; background: #2563eb; color: #fff; border-radius: 6px; display: flex; align-items: center; justify-content: center; font-weight: 800; } </style> </head> <body> <h2>Alinhamento no Grid</h2> <p class="dica">O container tem 100% de largura. O grid tem 3×90 = 270px de largura. Sobra espaço → justify-content: center funciona. 🧪 Missões Grid — do zero ao layout completo

Cada missão é curta e ensina uma coisa por vez. Faça na ordem. Leva cerca de 5-10 minutos cada. Se travar, abra a dica.

Grid: 0 de 5
Como funciona: marque Concluída ✓ só depois de ver o resultado na tela. O progresso fica salvo no navegador.

Primeiro Grid: duas colunas iguais

Objetivo: transformar uma lista vertical em uma grade de 2 colunas.

O que fazer
  1. Crie index.html com uma div class="grade" contendo 4 div class="caixa".
  2. No CSS, aplique display: grid em .grade.
  3. Adicione grid-template-columns: 1fr 1fr.
  4. Adicione gap: 12px.
  5. Dê a cada caixa um fundo colorido e um texto (1, 2, 3, 4).
Como saber que acertou
  • Aparecem 2 caixas por linha e 2 linhas no total.
  • Há um espaço visível entre as caixas.
  • Se você inspecionar .grade no DevTools, vê display: grid.
Se travar, clique para abrir a dica

O esqueleto mínimo é:

.grade { display: grid; grid-template-columns: 1fr 1fr; gap: 12px; }

Não esqueça: display: grid vai no pai, não nas caixas.

Mudar proporções: 1fr 2fr

Objetivo: entender que a unidade fr distribui o espaço em frações.

O que fazer
  1. Parta do código da missão G1.
  2. Troque grid-template-columns: 1fr 1fr por grid-template-columns: 1fr 2fr.
  3. Antes de salvar, escreva no papel: o que deve acontecer com a 2ª coluna?
  4. Salve e confira sua previsão.
Como saber que acertou
  • A 2ª coluna fica visivelmente mais larga que a 1ª.
  • Você consegue explicar que o espaço total é 3fr (1 + 2).
Se travar

Com 1fr 2fr: a 1ª coluna ocupa 1/3 da largura; a 2ª ocupa 2/3.

Página com cabeçalho, conteúdo e rodapé

Objetivo: usar Grid para montar a estrutura de uma página real (3 áreas).

O que fazer
  1. HTML: uma div class="pagina" com 3 filhos: header, main, footer.
  2. No CSS: .pagina { display: grid; grid-template-rows: auto 1fr auto; gap: 12px; min-height: 100vh; }
  3. Dê uma cor diferente para cada área (cabeçalho azul, conteúdo claro, rodapé escuro).
  4. Coloque padding nas áreas para o texto respirar.
Como saber que acertou
  • O main ocupa toda a altura restante entre header e footer.
  • Ao reduzir o zoom ou a janela, a proporção se mantém.
  • Não há rolagem vertical desnecessária.
Se travar

O 1fr na linha do meio faz o main crescer para preencher o espaço restante. Se ele não crescer, verifique se o .pagina tem altura definida (o min-height: 100vh resolve).

Grade de cartões responsiva (3 → 2 → 1 coluna)

Objetivo: combinar Grid com media queries para reorganizar cartões em telas diferentes.

O que fazer
  1. HTML: uma div class="grade" com 6 div class="cartao" (título + texto curto).
  2. Sem media query: grid-template-columns: 1fr (1 coluna — celular).
  3. Adicione @media (min-width: 600px) { .grade { grid-template-columns: 1fr 1fr; } } (2 colunas).
  4. Adicione @media (min-width: 1000px) { .grade { grid-template-columns: repeat(3, 1fr); } } (3 colunas).
  5. Use gap: 16px e teste em 360, 768, 1024 e 1440px.
Como saber que acertou
  • Em 360px: 1 cartão por linha.
  • Em 768px: 2 cartões por linha.
  • Em 1024px: 3 cartões por linha.
  • Nenhum cartão estoura a tela em nenhuma largura.
Se travar

Ordem das media queries importa: comece pela menor largura (mobile-first) e vá adicionando as maiores. As regras da maior sobrescrevem as da menor quando a tela é maior.

Se quiser, use só uma linha e deixe o Grid fazer o trabalho:

grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); — testa e compara com a versão com media queries.

Layout com áreas nomeadas (grid-template-areas)

Objetivo: desenhar o layout como um mapa — muito mais legível que decorar posições.

O que fazer
  1. HTML: header, nav, main, aside, footer dentro de .pagina.
  2. No CSS, defina grid-template-areas assim:
    "cab cab cab" "menu main lado" "pe pe pe"
  3. Aplique grid-area: cab; no header, e assim por diante (menu, main, lado, pe).
  4. Use gap: 10px e cores diferentes por área.
Como saber que acertou
  • O cabeçalho ocupa as 3 colunas em cima.
  • Na linha do meio há 3 blocos: menu, conteúdo, lateral.
  • O rodapé ocupa as 3 colunas embaixo.
  • Você consegue ler o CSS e "ver" o layout.
Se travar

Cada string dentro de grid-template-areas é uma linha. Cada palavra é uma coluna. Nomes repetidos fazem a área ocupar mais de uma célula.

Não esqueça: cada elemento filho precisa de grid-area: nome correspondente.

🟠 Flexbox: distribuir elementos em grupos

Flexbox organiza itens em uma direção (linha ou coluna) e distribui o espaço entre eles. É ideal para menus, cartões lado a lado, grupos de botões.

Flex container e flex items

display: flex no pai torna os filhos flex items. Por padrão, eles se alinham em uma linha.

Eixo principal e eixo transversal

Dois eixos: o principal é a direção em que os itens ficam organizados (linha por padrão). O transversal é perpendicular a ele. As propriedades justify-* atuam no principal; align-* no transversal.

Demonstração interativa

1
2
3
4
.container { display: flex; flex-direction: row; justify-content: flex-start; align-items: stretch; flex-wrap: nowrap; gap: 8px; }

flex-grow, flex-shrink, flex-basis

Controlam como cada item se expande/encolhe no espaço disponível.

  • flex-grow: fator de crescimento. 0 = não cresce (padrão).
  • flex-shrink: fator de encolhimento. 1 = encolhe (padrão).
  • flex-basis: tamanho inicial antes de crescer/encolher.
  • Atalho flex: 1 = flex-grow:1; flex-shrink:1; flex-basis:0.
Exemplo concreto: flex: 1 1 220px em cartões = cresce (1), encolhe (1), base 220px. Em um container com 4 cartões e flex-wrap: wrap, cada um tenta ter 220px; se não couber, quebra linha. Em telas grandes: 3 ou 4 por linha. Em celular: 1 por linha.

order e flex-flow

  • order muda a posição visual sem alterar a ordem do HTML. Use com cautela: leitores de tela leem na ordem do HTML.
  • flex-flow: row wrap é atalho para flex-direction: row; flex-wrap: wrap.

🛠 Missões Flexbox — componentes do dia a dia

Mesmo formato da aba 4: curto, uma coisa por vez. Se travar, abra a dica.

Flexbox: 0 de 5

Alinhar itens em uma linha

Objetivo: colocar 3 elementos lado a lado (o uso mais comum do Flexbox).

O que fazer
  1. HTML: uma div class="linha" com 3 div (A, B, C).
  2. CSS: .linha { display: flex; gap: 10px; }
  3. Dê a cada filho um fundo colorido e padding para visualizar.
Como saber que acertou
  • Os 3 elementos ficam lado a lado.
  • Há um espaço de 10px entre eles.
Se travar

display: flex vai no pai (.linha), nunca nos filhos.

Menu com logo à esquerda e links à direita

Objetivo: usar justify-content para distribuir elementos nos extremos.

O que fazer
  1. HTML: header.topo com span.logo e nav.links (com 3 links dentro).
  2. CSS: .topo { display: flex; align-items: center; justify-content: space-between; padding: 12px 20px; }
  3. Dê cor de fundo escura e texto claro.
Como saber que acertou
  • O logo fica colado à esquerda.
  • Os links ficam colados à direita.
  • O texto de ambos fica alinhado verticalmente ao centro da barra.
Se travar

justify-content: space-between empurra os dois grupos para os extremos. Se "não acontecer nada", verifique se o .topo tem largura suficiente (não é o caso típico).

Cartões que quebram linha automaticamente

Objetivo: usar flex-wrap: wrap para que cartões caiam para a linha de baixo sozinhos.

O que fazer
  1. HTML: uma div class="lista" com 4 div class="cartao".
  2. CSS do container: display: flex; flex-wrap: wrap; gap: 16px;
  3. CSS do cartão: flex: 1 1 220px; padding: 16px; border: 1px solid #ccc; border-radius: 8px;
  4. Coloque um título e um texto curto em cada cartão.
Como saber que acertou
  • Em tela cheia: vários cartões por linha.
  • Ao reduzir a janela: os cartões caem para baixo sozinhos (sem media query).
  • Em 360px: 1 cartão por linha.
Se travar

flex: 1 1 220px significa: cresce (1), encolhe (1), tamanho-base 220px. Quando a linha não cabe todos, o wrap joga os que sobram para a próxima.

Sem flex-wrap: wrap, eles tentariam caber todos em uma linha só — e ficariam apertados.

Cartão com botão sempre no rodapé

Objetivo: usar margin-top: auto para empurrar o botão para o fundo do cartão.

O que fazer
  1. HTML: um div.cartao com h3, p e button.
  2. CSS do cartão: display: flex; flex-direction: column; min-height: 220px; padding: 16px; border: 1px solid #ccc;
  3. CSS do botão: margin-top: auto;
Como saber que acertou
  • O botão fica colado no fundo do cartão, mesmo com pouco texto.
  • Se você aumentar o min-height, o botão desce junto.
Se travar

O margin-top: auto funciona porque o container é flex em coluna. Ele absorve todo o espaço livre acima do botão.

Grupo de botões centralizados

Objetivo: combinar justify-content + align-items + gap para centralizar botões.

O que fazer
  1. HTML: div.grupo com 3 button (Confirmar, Cancelar, Excluir).
  2. CSS: .grupo { display: flex; justify-content: center; align-items: center; gap: 12px; flex-wrap: wrap; padding: 24px; }
  3. Dê cores diferentes a cada botão.
Como saber que acertou
  • Os 3 botões ficam centralizados horizontalmente.
  • Se a tela ficar muito estreita, eles quebram para a próxima linha (wrap).
  • Se você mudar align-items para stretch, os botões ficam da mesma altura — teste!
Se travar

justify-content: center centraliza no eixo principal (horizontal). align-items: center centraliza no eixo transversal (vertical). Com gap, o espaçamento é uniforme.

📐 Responsividade com @media

Uma media query aplica CSS apenas quando a tela atende a uma condição (geralmente largura mínima ou máxima).

Sintaxe básica

media-sintaxe.css
/* Mobile-first: estilo base para telas pequenas */ .pagina { display: grid; grid-template-columns: 1fr; gap: 12px; } /* A partir de 600px, uma tela um pouco maior */ @media (min-width: 600px) { .pagina { grid-template-columns: 1fr 1fr; } } /* A partir de 1000px, desktop */ @media (min-width: 1000px) { .pagina { grid-template-columns: 1fr 1fr 1fr; } } /* Também é possível usar max-width (desktop-first) */ @media (max-width: 480px) { body { font-size: 15px; } }

Breakpoints comuns

LarguraDispositivo típico
até 480pxCelulares pequenos
481px – 768pxCelulares grandes / tablet retrato
769px – 1024pxTablet paisagem / laptops pequenos
1025px em dianteDesktops
⚠️ Não copie breakpoints de outros projetos. Defina breakpoints onde o seu layout quebra: se a 800px os cartões ainda cabem lado a lado, não force mudança só porque "um tutorial usou 768px".

Exemplo completo: layout que muda

Abaixo, um layout de três colunas que vira uma coluna em celular e duas em tablet. Os valores 600px e 1000px são apenas um exemplo — o seu projeto deve usar os valores em que o seu layout quebra.

responsivo.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Layout Responsivo</title> <style> *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; } body { font-family: Arial, sans-serif; padding: 16px; background: #f8fafc; } .pagina { display: grid; grid-template-columns: 1fr; gap: 12px; } .bloco { background: #2563eb; color: #fff; padding: 24px; border-radius: 10px; text-align: center; font-weight: 800; } @media (min-width: 600px) { .pagina { grid-template-columns: 1fr 1fr; } } @media (min-width: 1000px) { .pagina { grid-template-columns: 1fr 1fr 1fr; } .bloco { padding: 36px; } } </style> </head> <body> <div class="pagina"> <div class="bloco">Bloco 1</div> <div class="bloco">Bloco 2</div> <div class="bloco">Bloco 3</div> <div class="bloco">Bloco 4</div> <div class="bloco">Bloco 5</div> <div class="bloco">Bloco 6</div> </div> </body> </html>

Evitando rolagem horizontal

  • Nunca fixe width maior que a viewport em elementos de página (use max-width: 100% em imagens).
  • Prefira min-width em vez de width quando não for essencial ter tamanho fixo.
  • Em tabelas largas, envolva em um div com overflow-x: auto — assim a rolagem fica só na tabela.
  • Teste no DevTools em 320px — o mínimo comum entre celulares modernos.
✅ Teste rápido: redimensione a janela do navegador de 1200px até 320px. Se a página nunca gerar uma barra horizontal, o layout básico está responsivo.
